# 博客章节证据集

冻结 2026-11-12 的全部 10 篇公开文章，保留原始标题、正文及文章编号。
`manifest.json` 记录来源、内容版本、标注性质和数据权利范围；没有访问私密文章。
历史架构与项目介绍只作为当时文章的内容，不代表当前生产实现。

70 个项目 Agent 编写的问题包含 65 个有证据问题、5 个虚构标识符无答案问题。
问题先于检索结果编写，按 `SHA256(family) % 4` 分组：0 为 dev，其余为 test，
分别为 13/57 题；all 是诊断并集。问题家族不跨 dev/test，公开标签不构成盲测。
本轮不依据这些题调整检索参数，也不把相关问题数当作独立生产样本。

每个有答案问题复用扁平 `evidence_spans`：每条默认是必须覆盖的原文范围；
可选的同名 `group` 表示可替代范围。范围包含文章 ID、内容 SHA、章节解析版本、
小节 ID、节内字符坐标与精确原文。
已知文章问题使用 `scope_document_id`，运行器将其传给两路生产检索器。

加载器验证原文与坐标一致，不验证问题与证据的语义关系。标注尚待独立人工复核，
属于可复现的项目回归标签，不声称独立专家金标准。选取的证据位置并非全部相关位置；
漏掉一个指定位置应结合原文复核，不能直接推断检索结果完全无用。

使用现有三路模型入口运行 `--split dev` 或 `--split test`，见
[固定语料评测](../../offline-rag.md)。`PassageEvidenceCoverage@k` 要求候选中返回的
同一原文版本、同一小节范围完整覆盖选定证据，支持相邻/重叠片段合并，存在缺口则不算覆盖。
`AllPassageEvidence@k` 要求所有必要组均覆盖。文章命中、正文已读和回答正确分别报告。

无答案题的候选返回只记观察；本轮不生成回答、不恢复 LLM Judge，不能由候选存在推断幻觉。
