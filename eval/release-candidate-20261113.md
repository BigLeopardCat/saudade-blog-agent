## 正式版剩余条件

1. 固定最终安装与运行组合，重跑同版本完整回归，复核定点读量、导航和全部成本与时延分组。
2. 小批重复不能证明闲聊输入、长文输出等全量 P95 达标，继续按原门槛判定。
3. 严重事实、权限与执行结果错误仍须复核；语义评审未覆盖或未裁定不计通过。
4. 将组件确认、回放、取消恢复与 HTTP 准备评测分开；完成最终部署和恢复验收再决定正式 tag。
