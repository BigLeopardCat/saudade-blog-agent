## 正式版剩余条件

1. 减少定点问答的整篇读取、可避免的查询往返，并复核遗漏导航的场景；不增加关键词路由。
2. 固定最终安装与运行组合，试水通过后再做同版本完整回归，复核全部成本与时延分组。
3. 严重事实、权限与执行结果错误仍须复核；语义评审未覆盖或未裁定不计通过。
4. 将组件确认、回放、取消恢复与 HTTP 准备评测分开；完成最终部署和恢复验收再决定正式 tag。
