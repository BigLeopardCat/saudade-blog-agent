# 核心执行链路冻结证据

候选 `e0a0042b22de09e027ab29bd1623e4b1d89bd6bc` 完成 19 个核心场景和 6 个独立重复样本。
机器结果见[冻结报告](report/baseline_e2e_closeout_20261113.json)；这份证据属于该候选，
不作为后续版本完整线上回归已通过的证明。当前发布判断见[验收状态](release-candidate-20261113.md)。

## 验证边界

使用真实 OpenCode Go / deepseek-v4.1-flash，业务 API 与浏览器回执为合成夹具，
执行账为临时 SQLite、checkpoint 为内存。PostgreSQL 和 Playwright UI 行为由独立 CI 验证。
本批没有生产业务写入、线上真实浏览器执行或语义 judge 调用。

验证的行为包括：

- 确认前零写入；批准后只写一次，重复令牌不能重放业务操作。
- 部分写入失败后独立查询已完成对象，未知状态不冒充成功。
- 后续用户要求撤销旧卡，管理员多项操作遵守各自授权边界。
- 暂停后恢复、运行时重建及 checkpoint 接续保留未完成任务。
- 浏览器回执核对任务、command_id、目标和状态；错误关联不消耗恢复点。
- completed、failed、timeout 分别核验；缺失、foreign 和重复回执不调用模型或重发动作。
