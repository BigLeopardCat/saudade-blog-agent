- 将工作输入、模型窗口、累计任务 token、调用次数与活动执行时间分别约束；暂停、审批与重建沿用持久预算。部署需用 `AGENT_TASK_TOKENS` 替换 `AGENT_REQUEST_TOKENS`，并配置 `AGENT_TASK_SECONDS`，不保留旧参数别名。
- 容量触发的分段摘要复用 LangChain middleware 与 LangGraph checkpoint。恢复和审批接续经过同一容量边界；任务预算不足明确停止，不通过继续裁剪历史尝试调用。
- 预算耗尽仍提交已知回执与终态；未开始的取消不占执行账，未知写入可核实但不能重放执行。
- 严格区分缺失、非法和真实零 usage；记录脱敏工具/消息/参数指纹、变化位置及摘要/恢复标记，并在验收报告区分成功、失败与未评审任务用量。
