# 博客 Agent 发布验收

本文是当前发布目标；历史回归报告只代表其冻结版本。机器目标源为
[`eval/release_profile.json`](../eval/release_profile.json)，检查入口为
`python -m eval.release_readiness`。目标适用于个人博客的低并发文本助手，
不是已取得的生产成绩，也不是所有企业的统一标准。

反馈复核、独立数据封存和候选到发布审查的操作入口见
[离线改进流程](offline-improvement.md)。它复用本文目标，不能用候选生成成功替代验收通过。

## 发布门禁与质量观察

| 检查 | 发布要求 | 证据 |
| --- | --- | --- |
| 越权、未确认写入、隔离失效 | 所有关键用例明确通过 | 可信身份、工具调用、确认事件、宿主写入与执行回执 |
| 核心功能与权限契约 | 关键用例明确通过 | 读取目标、导航目标、资源归属、准备确认、恢复与停止后继续 |
| 重复执行与未知结果重放 | 0 次 | 隔离后端、执行账和故障恢复契约测试 |
| 证据完整性 | 完整采集，版本与冻结 trace 一致 | 证据缺失、采集错误或关键合同未通过时禁止发布 |
| 回复质量与模型评审 | 记录趋势和已确认问题 | 总体、核心、身份和领域的分组成绩与人工复核 |

版本 4 的 HTTP 发布判定使用功能契约。模型评审可选，语义通过率和待审数量进入报告。
旧报告中的 95% / 98% 保留为观察参考。空回复、错误链接、错误导航目标等明确交付要求
仍由客观断言覆盖。安全用例已独立断言零执行、无业务写入和禁止工具时，通用拒绝措辞
单列为答复质量观察。真实越权、误写、跨身份数据披露或凭空声称高风险操作已执行，
经工具、宿主或回执证据确认后继续拦截发布。

`checks_passed` 只表示评审材料未发现问题。judge 误判和已确认的正文问题都保留原始报告、
复核依据和责任人。待审与未评估在语义报告中保留原状态。版本 1～3 的冻结报告继续使用
各自归档的配置与原判定。

评审判例、分组统计与测量口径见[评测与可观测性](eval-observability.md#语义评审判例)。

模型视觉识别属于可选诊断，不纳入发布验收。宿主图片展示仍按浏览器契约验收。
确认前停在卡片属于正确行为；
确认后的数据库事实、浏览器实际跳转、卡片布局和交互体验必须另外验收。
线上 HTTP 套件不批准业务写入，不把准备成功说成端到端执行成功。
不带浏览器回执的 HTTP 用例仅返回 `sent` 时，不审查页面完成措辞，也不计网页交互成功。
正式网页端必须等待真实浏览器回执后回复；失败或超时不得报成功，由浏览器链路测试验收。
该范围限定不覆盖错误目标、权限、业务写入和设备执行结果。

## 按改动选择验收范围

先确定变更影响，混合改动覆盖每一项相应风险。发行包要通过适用的离线检查，并核对包内版本、源码提交及附件校验和。关键功能、权限、确认、幂等、隔离和恢复的可复核证据继续作为门禁。

| 改动范围 | 需要核对的证据 | 真实模型验证 |
| --- | --- | --- |
| 文档勘误、导航或教程 | 本地链接、标题锚点、示例与当前契约对齐 | 文档可按静态证据交付 |
| 看板娘、界面或展示状态 | 受影响的前端检查和浏览器回归。跨仓挂载组件时核对宿主 pin 与实际资源 | 模拟请求与返回即可验证界面契约 |
| 局部运行时补丁、依赖或安装变更 | 受影响的离线契约。发行时验证包与安装，运行环境或状态变更时补升级与恢复 | 离线证据足以覆盖改动时，记录本版离线验证范围 |
| SSE、鉴权、确认、写入或迁移 | 用隔离夹具验证两端契约、旧版本兼容、失败路径及适用的升级回滚 | 仅当用户可见行为也依赖模型判断时，补受影响的模型场景 |
| 提示词、工具选择、RAG、模型或模型执行策略 | 以原问题和冻结候选做对照。先验证受影响的链路、权限和证据，再根据影响面扩大样本 | 小批量 POC 确认身份、数据、trace 和供应商可用。模型主链或多个核心场景普遍受影响时跑完整文本套件 |

完整文本套件使用同一冻结候选，至少 100 个场景，保留首次结果及有界框架重试的消耗。一次定向通过支持该场景的判断。供应商或采集错误单列，未完成和未评估明确记录。模型语义评审按需用于调查质量问题。

## 发布步骤

冻结 Agent、宿主、组件与适用的数据库迁移，先记录本次需要的验证范围，再运行相关检查。涉及安装包时核对 README、CHANGELOG、发行说明和安装入口。将每项证据关联到实际候选，并标注仍未验证的范围。[发行维护](releasing.md) · [评测入口与指标](eval-observability.md)

按改动选取相关证据。尚无记录的项目标记未验证。

| 证据 | 至少记录什么 | 验证阶段 |
| --- | --- | --- |
| RAG 与引用 | 排名/证据覆盖、无答案题、引用与正文一致、过期或不可见内容处理 | 固定检索集与任务级审查 |
| 真实交互 | 浏览器完成回执、确认/取消/继续、断线恢复、无重复执行 | 浏览器及隔离写入夹具 |
| 稳定性 | 超时与错误、取消后资源释放、4会话负载下延迟与资源占用 | 候选部署验收 |
| 成功任务成本 | 全部尝试费用/已验收成功任务数，并列失败和未评估消耗 | 同一模型、构建、价格口径 |
| 运行与恢复 | 健康探测、异常告警、升级回滚与持久状态恢复验证 | 发布前演练及发布后持续观察 |

这些是互补证据，不合成一个加权总分；安全故障不能被低成本或高平均通过率抵消。
