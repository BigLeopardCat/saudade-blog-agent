# ADR-0026：工具激活状态独立于历史窗口

- **状态**：已采纳；跨任务继承部分由 [ADR-0030](adr-0030-task-tool-scope-and-resource-exit.md) 替代。
- **范围**：框架任务 state、工具目录、身份隔离和暂停恢复。
- **判据**：`tests/runtime/test_tool_state_lifecycle.py`、`tests/runtime/test_context_contracts.py`。

子图的 `loaded` 是同一任务恢复的唯一激活来源。按当前授权目录重建定义并保留顺序，不扫描历史 ToolMessage、摘要或宿主记录猜测工具集合。权限与实际工具契约始终需要重新核验；保持缓存不能覆盖权限边界。

会话原文、摘要和任务工具的生命周期相互独立。历史压缩不卸载当前任务工具，新任务不继承已完成任务的完整目录。无需为旧 checkpoint 补写激活字段，也不维护会话与任务之间的第二份镜像。

离线测试验证布局、隔离和恢复；实际缓存收益与任务成本取服务商 usage，区分新任务与同任务恢复，不把单一缓存命中率当成验收结论。
