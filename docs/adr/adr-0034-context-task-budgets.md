# ADR-0034：工作上下文与持久任务预算

状态：采纳。范围：模型输入、摘要、跨请求资源记账与缓存诊断。

## 决策

继续使用 `create_agent`、标准 `SummarizationMiddleware` 和 LangGraph checkpoint。
应用只提供来源过滤、完整请求计量、业务资源上限与跨 HTTP 持久记账。

- 模型窗口包含输入与输出；工作输入包含系统消息、历史、工具定义及参数，不重复扣除输出。
  默认工作输入 128K；生产模型窗口独立配置为 1M。这些是容量上限，不是费用或检索质量承诺。
- 输入接近有效容量的 80% 才压缩，目标约 40%。超大旧历史分段处理，切点不拆工具交换；
  每段由标准 middleware 消息更新落 checkpoint。恢复复用已完成覆盖范围，不重新导入旧正文。
- 当前任务原始要求和执行中用户补充保留原文，待确认交换及其回执先恢复，再评估容量。
  已激活工具来自任务 state，摘要不能激活工具、授予权限或证明执行成功。
- 任务累计 token 默认 1M，模型/工具次数 12/16，活动时间 300 秒；摘要与接续共享。
  任务额度不足直接结束，不能通过裁掉任务依据或切换执行器绕过。预算停止仍提交已知结果。
- 每次活动 HTTP 预留至其截止时间和任务剩余时间的较小者，正常退出结算实际活动时间；
  人工等待不计时，进程失联保留预留。该数值是保守计费预算时间，不能冒充纯观测墙钟时间。
  未带时间账的旧活动任务禁止新增业务执行，允许消费回执、关闭审批与重新发起。
- 摘要失败但仍需应急缩小模型视图时，保留当前完整任务并显式标记上下文缺口；
  超大当前任务直接拒绝，不能截断目标。原始业务/聊天资料仍可通过有权限的历史工具核实。
- 请求指纹只记录哈希、规模和时区明确的时间。逐消息、逐工具和生成参数分别比较；
  首次观测不等于冷缓存，相同请求也不保证提供商复用。工具追加的效果必须实测。
- input 包含缓存输入；reasoning 是 output 子集。缺失或非法数据保持未知；无价格不估费用。
  任务结果、调用次数、未缓存输入、摘要开销及失败浪费分别报告，不以全局命中率替代质量。

## 记忆边界

会话 checkpoint/带来源摘要、任务工作状态和业务检索各自持有权威资料。
当前不启用跨会话长期偏好自动写入，也不从模型猜测生成用户画像。
将来启用长期记忆必须采用用户归属的 Store，附来源、时间和更正/删除入口，另行验收。

## 代价与限制

分段摘要会额外消耗模型调用，仍受同一任务预算约束；预算不足时明确停止。
无法仅靠 HTTP 取消承诺上游停止计费，未知调用保留预留。
紧急视图裁剪、实际摘要、角色变化及新任务工具集合都可能改变缓存前缀。
增加缓存前缀长度不是保留无关历史、越权工具或延长敏感数据寿命的理由。
