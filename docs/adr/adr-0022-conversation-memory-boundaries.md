# ADR-0022：会话历史按来源裁剪，图片按需回看

- **状态**：已采纳（20261025）
- **影响范围**：原生会话历史、宿主上下文、请求预算与历史图片读取
- **判据**：`tests/runtime/test_memory_boundaries.py`、`tests/test_conversation_images.py`

## 背景

合法图片的 base64 长度会触发文本保护阈值，并在 checkpoint 回放时影响后续纯文本轮次。
长中文输入也可能因超过普通历史窗口而消失。角色过滤只覆盖逐轮消息，无法确定宿主
旧摘要的生成权限；当前身份不足以证明旧数据是在相同角色下产生的。

## 决策

保留标准消息、框架计量器和现有 saver；近期完整问答优先，实际可用预算不足时明确节选。
最近一轮的助手长回复与工具事实无法同时放入历史窗口时，优先保留能放下的最近完整
工具调用与结果，再节选助手回复；保留用户原文，维持原有权限过滤和总预算。
图片字节只在当前轮或按需回看时进入模型输入，持久历史保存引用及已有分析。
复用宿主现有鉴权历史接口，不创建媒体数据库、额外描述模型或向量会话记忆。

宿主历史和摘要须提供生成时保存的身份、会话和角色来源，缺少来源时停止自动注入。
这会限制旧宿主的自动摘要和空库导入，具体接线及迁移要求见
[会话记忆契约](../conversation-memory.md)。不通过事后补标来源掩盖这个兼容影响。
确认卡、签名、幂等账、会话锁和删除屏障继续独立工作，不由历史或摘要推导执行权限。
