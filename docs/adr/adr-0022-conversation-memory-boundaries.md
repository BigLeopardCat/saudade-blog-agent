# ADR-0022：会话历史按来源裁剪，图片按需回看

- **状态**：已采纳；取代 ADR-0013 中历史图片仅展示的范围限制。
- **核对日期**：2026-11-09。
- **历史来源**：[删除前记录](https://github.com/BigLeopardCat/saudade-blog-agent/blob/5e3d89e18f77ea0edf5c89811deb1346f02e80aa/docs/adr/adr-0022-conversation-memory-boundaries.md)。

## 背景与决策

历史图片的内联编码会挤占文本预算，缺少来源的旧摘要也无法证明生成时的身份权限。
持久消息保留有来源的文本、工具事实与图片引用；图片字节仅在当前轮或有权限的按需回看时入模。
复用宿主历史接口，不另建媒体数据库、自动描述模型或向量会话记忆。

历史按身份、会话、角色来源和实际输入预算过滤。缺少可信来源时不自动注入，
不能事后补标以掩盖旧数据的兼容问题。保留可用的完整工具交换和用户要求，
节选与上下文缺口须明确，不能破坏工具消息配对。

## 边界与验证

摘要和图片分析都不是授权凭据，也不能证明业务写入成功。权限、确认签名、
独立执行账和删除屏障继续工作；模型需要图片时仍核对会话归属、固定来源、哈希和下载上限。

当前上下文、分段摘要和图片读取见[会话与记忆](../conversation-memory.md)，
回归见 `tests/runtime/test_memory_boundaries.py` 和 `tests/test_conversation_images.py`。
本决策不承诺无限历史，也不因扩展模型窗口而自动延长敏感数据寿命。
