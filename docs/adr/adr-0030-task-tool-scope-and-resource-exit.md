# ADR-0030：工具生命周期与明确资源终止

- **状态**：预算退出与框架边界已采纳；原跨任务全部清空规则已由有界热工作集替代。
- **核对日期**：2026-11-09。
- **历史来源**：[删除前记录](https://github.com/BigLeopardCat/saudade-blog-agent/blob/538b84c56820979d8dbb49dcbf7ff0938a396c93/docs/adr/adr-0030-task-tool-scope-and-resource-exit.md)。

## 背景与保留的决策

继承过多领域会挤占输入和任务预算；把工具全部卸载后再调用一次模型“收尾”，
可能把未完成请求包装成正常成功。模型循环、动态工具和摘要继续使用框架公开接口，
应用在资源不足时明确停止并保留已知事实。

硬预算耗尽记录实际受阻原因，不能改变输出预算、删除任务依据或换执行器再付费推进。
身份、签名、幂等与跨 HTTP 累计预算仍由应用保障，
不能用只计算单次调用的限制假装覆盖整个任务。

## 当前工具生命周期

原记录要求新任务不继承上个任务目录；后续主线改为同身份范围内的有界热工作集，
见 `agent/runtime/tool_state.py`。权限匹配、最近使用和 schema 软目标共同约束继承，
容量压力时释放闲置领域，当前任务需要的领域受保护，完整请求仍受硬预算限制。

同任务的确认、浏览器等待与恢复沿用 checkpoint 中的目录并重新核对授权；
不能扫描摘要或旧消息猜测激活状态，也不另建脱离框架的菜单缓存。
原 ADR-0026 的历史独立性由此承接，跨任务范围以当前实现为准。

## 取舍与验证

服务商工具搜索和额外 LLM 选择器不能仅凭 OpenAI 兼容格式直接采用；
需验证实际端点能力、多轮上下文、额外调用和总任务成本。
当前有界目录没有强制增加一个选择模型。

回归见 `tests/runtime/test_tool_state_lifecycle.py`、`tests/runtime/test_budget_exit.py`；
当前配置与用量口径见[会话与记忆](../conversation-memory.md)。
缓存命中率或领域数量不能代替任务质量。
