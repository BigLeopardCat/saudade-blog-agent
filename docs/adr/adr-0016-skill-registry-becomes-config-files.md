# ADR-0016：技能注册表从 Python 字面量改成**一条技能一个 TOML 配置**

- **状态**：已采纳（20261021）—— 试点域（公开读两条）已落地，其余五域逐个转
- **背景文档**：`docs/agent-architecture.md` §2、`agent/workflow_defs/loader.py`（头注是这条
  决定的正文）
- **影响范围**：`agent/workflow_defs/`（新增 `loader.py` 与 `*.toml`，删 `public_read.py`）；
  `agent/workflow_defs/__init__.py` 的拼回那一行；`eval/judge_registry.json` 的
  `metric.by_file` 与 `total`；`docs/agent-architecture.md` §2。**`Workflow` 数据模型、
  展开层、planner 提示词、判据一个字未动**——50 条技能逐字段逐字节相同。
- **判据**：`tests/test_workflow_config.py`（五组：试点域逐字段相同 / **格式表达力往返**
  （全部 50 条过一遍配置格式再回来必须原样相等，附灵敏度反控）/ 六种坏配置全部响亮抛 /
  TOML 与 Python 两边的技能名**不相交**且并起来正好 50 条 / 顺序契约）。
- **触发条件**：若"逐字段相同"这条判据开始需要**放宽**（比如某条技能的表达需要 TOML 表达
  不了的东西），那就是格式选错了，重开这一份；不许用"给 loader 加一个逃生舱"来绕过。

## 背景

技能（`Workflow`）是**数据**：触发条件、参数说明、完成判定、回复契约——全是发给模型的话。
但它此前长成 Python 字面量：六个域模块、50 条 `Workflow(...)`、**2554 行**。

那形状有两个代价：

① **加一条技能要在一个几百行的 `.py` 里找位置**。`agent/workflows.py`（**已删**：20261017
   拆成 `workflow_defs/`）时代它占该文件 36%（1691 行），按域拆之后单模块仍有 110–635 行。这与主人
   20261017 / 20261021 两次点名的「改动不断叠进同一个文件」「禁止上帝文件」是同一件事；
② Python 字面量换来的是"能塞表达式"这个**没人用**的自由，付出的是"改一句话要过一遍代码
   的形状"——而注册表里**一个表达式都没有**。

实测的格式体检（`--dump` 全 50 条，20261021）：`plan` 实参共 **83 个值，只有 str 与 bool、
零个 `None`**；散文里**没有反斜杠、没有三引号**；`description` 的换行数分布是 **38 条 0 个 /
12 条 1 个**（那 12 条正是带"必须怎么做"契约的，`Workflow.contract` 按第一个 `\n` 切）。

## 决策

**一条技能一个 TOML 文件**，`loader.load_dir()` 读成 `Workflow`。格式要点：

- **TOML**，用标准库 `tomllib`（本仓已在 3.12）⇒ **零新依赖**；
- **`extra="forbid"`**（pydantic）：打错一个键名当场抛。配置文件的失效天生是静默的
  （写错 `complete_wen` ⇒ 完成判定没了，模型照跑、判据照绿）⇒ "多一个不认识的键"必须比
  "少一个键"更响；
- **散文用多行基本字符串 + 行尾 `\` 续行**：TOML 的续行会吃掉换行与下一行的前导空白
  ⇒ 每一行的断点与原来 Python 相邻字符串字面量的断点**一一对应**，读起来就是那份源码。
  ⚠️ 换行必须是**显式 `\n`**——第一个换行是契约切点，靠缩进表达换行会让那条切法静默切错；
- **`order` 是稀疏排序键**（位次 6 → `order = 60`），不是"第几名"：留出空档 ⇒ 插一条技能
  不用给后面几十个文件逐个重编号。

## 取舍

**为什么不是 YAML。** `yaml` 在盘上装着（6.0.3），但**既没被 `pyproject.toml` 声明、也没有
任何一行 import 它**——用它就是给运行时塞一份没人复核的依赖。本仓纪律是「依赖名单 = 代码里
真的 import 了什么」，而这条纪律正是为了让"多一份依赖"成为一个要写下来的决定。

**为什么不是 JSON。** 没有多行字符串 ⇒ 三十行散文会变成一坨带 `\n` 的单行，改一个词要在
转义里数括号。这条改造的全部收益是**可维护**，选一个让人不想打开文件的格式等于白做。

**为什么不是 SKILL.md（YAML frontmatter + markdown 正文）。** 那要自己切 frontmatter——
一段自造的解析器，而它恰恰是最容易静默出错的地方（少一个 `---`、正文里出现 `---`）。
本仓刚在 20261020 记过一条同族教训：**"散文外置"不等于"散文随便放"**，`\n` 在本场景是
**有语义的**（契约切点），markdown 的软换行会把它搅浑。

**为什么一条技能一个文件，而不是一个域一个文件。** 按域分只把 1700 行降成 110–635 行，
"加一条技能要在一个共享文件里找位置"这件事**一点没变**；按技能分则是"加技能 = 加文件"，
不撞别人的 diff，一条技能的正文与它自己的注记住在一起（试点域那两个文件里搬过去的
长注释就是证据）。

**为什么不把 `nav_map.py` / 写靶通道表 / `capability.py` 一起搬。** 三者各有理由：
`nav_map` 是**匹配器**（不是话术）且同时被 `tools/` 读，它的 75 个中文集合正是中文词表闸
该看的东西；写靶通道表是**派生件**（"注册表 → 视图"的推导，不是技能本体）；
`capability.py` 是跨技能共用的散文片段。**判据是"它是这条技能的定义吗"**，不是"它看起来像数据吗"。

**代价（如实记）**：`judge_registry.json` 的中文穷举量是**按文件**记的，而 TOML 不在扫描面里
⇒ 试点域那 1 处中文 dict（`content_query` 的 `inputs`）**移出了词表闸的视野**。移出的是
**话术**（`prompt_text`：只进提示词/卡面，没有任何判定分支读它），不是匹配器 ⇒ 按
`eval/wordlist_gate.py` 头注自己的分类，闸本来也不该管它。动作是**销账**
（`agent/workflow_defs/public_read.py [1,0]` 删键、`total` 1151→1150、新文件 `loader.py` 记
`[0,0]`），**不是 `--update`**。后续每转一个域都要按同一口径销账并说明移出的是什么。

## 复验

| 要验的性质 | 判据 |
|---|---|
| 转过去的技能**逐字段没变** | `tests/test_workflow_config.py` ①（含 `order` == 位次/10） |
| **格式表达得了全部 50 条**（不只转过的那两条） | 同 ② 的往返 + 灵敏度反控 |
| 坏配置**响亮**而不是静默取缺省 | 同 ③（未知键 / 缺必填 / 名字与文件名不符 / order 撞 / 语法坏 / 空目录） |
| **两边不许各留一份**（转一半是最坏的中间态） | 同 ④（名字不相交、并起来 == 50、`public_read.py` 已删） |
| 顺序契约 | 同 ⑤ + `tests/test_registry_sync.py` / `test_workflows.py`（读 `WORKFLOWS` 本身） |
| 判据面没有静默缩小 | `eval/wordlist_gate.py`（销账那一格 + 总账收紧） |
| 模块层级与预算 | `tests/test_module_index.py`（§2 有行）、`test_module_exports.py`（`__all__`）、`test_module_budget.py` |
