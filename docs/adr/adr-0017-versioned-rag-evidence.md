# ADR-0017：版本化语料、不可变向量代与正文证据约束

- **状态**：已采纳（20261023）
- **背景文档**：[RAG 设计](../rag-design.md)
- **影响范围**：宿主语料接口、rag/、文章工具、默认图、可选运行时和评测
- **判据**：tests/test_rag_contracts.py、tests/test_rag_evidence.py；宿主 rag_corpus 和 rag_corpus_pg 测试

## 背景

旧分页缺少内容版本和完整性信号，故障可能成为末页；标题在切片时丢出检索文本。
固定二进制、行映射和 manifest 分别覆盖，不能保证中断时读到同一代。
调用过检索工具不等于拿到正文，续读也缺少版本绑定。

## 决策

新增版本化公开语料端点，复用可见性谓词，在只读 repeatable-read 事务中取得页与摘要。
Agent 验证完整同版本快照才提交索引，不静默回落旧列表。

保留词法和可选向量架构，统一索引文本、文档聚合和 BM25 长度定义；
使用有上限、重叠与来源范围的结构切片，不增加检索服务或供应商绑定。

向量采用内容寻址不可变代和单一原子 manifest，读者验证摘要。
旧格式重建，不从无法证明正确性的旧缓存推断向量。查询缓存按完整空间隔离。

正文按版本绑定的小节或范围读取，预算渲染维护真实续读位置。
默认图补齐正文计划，可选运行时登记正文证据并校验来源。
站内问题判断不进行网络 I/O。

## 取舍

双仓先部署宿主，再部署 Agent；新增路由不改变前端旧文章端点。
向量升级需要一次重嵌。读取预算有限，超长问题可能需要缩小范围。
相关性与语义忠实度仍需真实模型及固定语料评测。

## 复验

修改协议时运行双方测试，并将真实宿主响应交给 Agent 解析器。
缓存故障测试覆盖各提交步骤及 ID→向量内容，加载成功不是充分判据。
评测携带内容、查询、配置和代码摘要，不继承旧命中率作为新设计成绩。
