# Agent：从零部署、读懂和使用

Agent 是接在博客中的任务助手，能读取真实来源、调用工具并在人工确认后处理业务。它不根据聊天自述提升身份，也不会把提议当成已执行。

## 推荐顺序

尚无站点时先走[博客安装](https://github.com/BigLeopardCat/Saudade-Blog/wiki/Installing-and-Upgrading)。随后按“配置 → 功能 → 前端交互 → 确认与恢复”练习。

## 截图与版本

截图来自真实组件的隔离浏览器场景，使用合成账号、示例域名与占位图片，不是生产后台或真实生图质量证明。
每张图放在对应步骤旁；先看图下说明，再按自己的账号和版本操作。配置密钥不会出现在截图中。
