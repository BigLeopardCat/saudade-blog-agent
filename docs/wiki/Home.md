# 泠月喵使用与开发教程

这里按任务说明怎么使用助手、如何审阅操作，以及怎样开始阅读实现。
能力受当前账号、宿主版本和已启用服务约束；教程不授予权限。

| 想做什么 | 教程 |
| --- | --- |
| 找文章、一起阅读、总结全文 | [聊天与文章阅读](https://github.com/BigLeopardCat/saudade-blog-agent/wiki/Using-the-Agent) |
| 审阅写入，处理取消与未知结果 | [确认与恢复](https://github.com/BigLeopardCat/saudade-blog-agent/wiki/Approvals-and-Recovery) |
| 协作修改标题、正文、摘要和封面 | [协作写作](https://github.com/BigLeopardCat/saudade-blog-agent/wiki/Writing-with-the-Agent) |
| 安排提醒、只读报告和定时操作 | [后台计划](https://github.com/BigLeopardCat/saudade-blog-agent/wiki/Background-Tasks) |
| 从请求读到工具与业务结果 | [读码练习](https://github.com/BigLeopardCat/saudade-blog-agent/wiki/Reading-the-Code) |
