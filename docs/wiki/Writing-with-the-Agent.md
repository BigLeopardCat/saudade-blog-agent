# 协作写作

需要管理员身份和已接入的博客编辑器。先在开发或自己的草稿中练习。

## 改正文和标题

1. 打开待编辑文章，核对文章标题及当前草稿。
2. 提出明确范围，例如“只润色这段，保留事实、代码块和引用，不发布”。
3. 等助手读取编辑内容并提出修改，在编辑器差异视图逐段审阅。
4. 采纳需要的部分，检查保存状态，再决定是否发布。

![编辑器的真实差异与采纳入口](https://raw.githubusercontent.com/wiki/BigLeopardCat/Saudade-Blog/assets/editor-review.jpg)

图：合成文章的红删绿增差异，正文和建议分开呈现。

助手提出修改不等于数据库已保存。冲突时重新读取并合并，不覆盖其他编辑的新版本。
长差异内容在编辑区域滚动查看，不能只看第一屏就全部采纳。

## 摘要、封面和发布

文章摘要通过聊天确认卡审阅后应用；修改摘要不意味着发布文章。
封面选择需要核对真实图片和版式；生成图片、保留入库、选为封面、发布文章是独立决定。

图库、生图和发布的完整操作步骤由博客维护：
