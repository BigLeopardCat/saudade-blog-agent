# P3：任务事件与对话交互验收

本批收敛确认卡、请求归属、导航回执和执行进度。主循环继续使用 LangChain Agent 与
LangGraph checkpoint；浏览器只保存展示投影，不增加业务执行状态机或自动重放机制。

- 对话组件：`252fe0bb6e3cb86d51fde560cfb528d63f87f480`；相对前项仅修改前端和浏览器测试。

## 交付与边界

确认卡绑定签名操作和实际来源回复。旧卡的成功、未知结果或撤销回包不能结算其替代卡；
相同正文的不同消息保持独立。历史来源未加载时，当前有效卡单独展示，不猜测挂到最新回复。

重载及跨标签页变更通过只读接口查询 checkpoint。宿主验证登录、本人会话及当前角色，
Agent 再核对任务、签名和审批状态。查询不等待模型轮锁、不调用模型、不签发新授权、
不执行业务，响应禁止缓存。本地只存 64 条、24 小时的展示记录并清除旧授权缓存；清理缓存
不会重建全部历史卡片注记，服务端审计副本仍保留。

请求绑定账号、会话和轮次，切换身份中止旧输出。旧收尾和暂停修复计时器不复位新任务，
新轮次使在途旧卡查询失效。导航回执核对账号、会话、任务、命令与路径，区分到达和超时；
重复命令不再跳转，回传结果后刷新仅恢复 checkpoint，不再次提交到达结果。

进度按调用标识去重，最多 24 条并随框架 checkpoint 恢复；不同同名调用分别显示，
继续任务不重复通用处理提示，预算耗尽后安全丢弃排队事件。参数、结果正文、授权不进入标签。
执行中补充沿用有序输入链路：下一模型边界生效，未发布提议可重算，已完成写入不追溯改变；
接收与生效分别显示，无法应用的输入有明确状态。

SSE 保持 v2，单连接顺序消费并校验终止边界；不自动重连执行业务。语义身份负责去重，
断连后通过服务端状态或显式原任务续接恢复。

## 本次线上时延与用量

7 次成功只读查询耗时 13.25～50.69ms，中位 14.58ms，不调用模型；另外两次分别验证
未登录 401、其他账号访问会话 404。真实收藏准备为 20.54s，首个可见事件 1.30s，
卡片到达 20.49s。三次模型调用依次是领域发现、生成准备调用、解释预览；最后解释
耗时 9.54s。这仍是 P4 需要关注的延迟样本，不能把交互恢复通过写成全部性能达标。

本例总输入 7,737，其中缓存 3,712、未缓存 4,025；输出 168，reasoning 42 为输出子集。
一个新会话准备任务不足以估计整体缓存命中或延迟分位数，也不能与 P2 暖会话指标混算。

本批不替代真实模型全量质量验收，不产生 P95 或全局缓存命中率结论。
全量基线、分层质量判据和文档收口继续按 P4 推进。
