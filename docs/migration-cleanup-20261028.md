## 当前执行边界

- 模型循环使用 LangChain `create_agent`，持久子图、审批与接续使用 LangGraph
  `StateGraph`、`interrupt`、`Command`。没有旧 planner、DSL 或实验臂回退。
- 服务适配器负责 HTTP/SSE、请求预算和资源生命周期；领域工具由模型选择。
- 授权、版本、签名确认、撤销、执行账和删除屏障是业务一致性边界，继续保留。
- 动态工具通过框架 middleware 接入；公开扩展点允许自行执行工具，不应仅凭这点判为自造框架。
