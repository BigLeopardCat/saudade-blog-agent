# 工具型 Agent 迁移路线

**状态（2026-10-22）**：聊天、按需领域工具、会话并发保护及收藏目标核对、确认准备、确认后执行及待办修改、取消已接入。
`AGENT_ARM=hybrid` 显式启用，默认仍为 `graph`。

**完成度约 55%**，按能力迁移和验收范围估算。主干与会话基础已建立，读领域仍需扩大
覆盖；写领域已接入单件收藏的确认准备、修改、取消与执行，其余写领域、完整验收、默认切换和旧图删除尚未完成。

## 目标边界

- 模型负责答复、选择相关工具、读取结果后决定下一步；只有复杂任务才进入有界循环。
- 代码负责身份与权限、确认、参数校验、幂等和真实执行回执。
- 工具按领域注册和加载。普通对话无需工具，站内任务只见到当前相关的工具 schema。
- 会话、任务和回执使用结构化状态；提示词只携带本轮必要的事实。
- 业务操作 ID 独立于编排引擎。复用现有鉴权、确认签名、PostgreSQL 幂等账和回执协议。
- 旧图只承担尚未迁移的领域；每个领域迁完即删除对应规划模板和纠偏分支。

## 已实现：普通对话单次调用

`agent/runtime/hybrid.py` 负责会话准入、上下文和持久化，`agent/runtime/session.py` 负责
单次请求的模型与工具循环，`agent/runtime/read_tools.py` 登记只读域与权限边界。
小上下文路径包含人格与短边界说明、至多两轮近期对话、
三个公开文章只读工具、站点资料、个人只读与收藏领域的按需加载入口，以及一个过渡期
交接工具。普通聊天一次调用；文章问题允许模型在有界循环中自主检索、读正文和答复；
站点资料加载后提供作者信息、社交链接和功能结构图三个公开工具。个人只读入口只向
**已验签、具备 `read.own` 权限且 uid 有效**的身份显示，加载后可查自己的收藏、
通知和站内信；实际调用前再次检查授权。工具白名单启动时核对 scope 声明。
选择交接时保留原始输入与授权状态；恢复标记在取得会话锁后重新读取。
直接路径最多使用 4 次读取、4 轮追加调用；单条工具结果最多 8000 字符，
累计工具结果最多 16000 字符，模型提示内容超过 24000 字符即交接旧图。
已确认的单件收藏操作进入新事务执行器；其余确认兑现、待确认操作和未完成任务进入旧图。配置图持久化时，直接路径从
checkpoint 中读取最近的用户与助手对话；答复先同步写回同一张图的 checkpoint，
然后才发送给客户端。待处理的 checkpoint 状态交给旧图，写入失败则不发送未持久化
答复。外壳提供同步状态接口，异步状态操作在线程中调用同步 PostgreSQL saver，供
恢复判定和丢弃末轮复用。收到停止信号后，在模型调用返回时终止，不再继续读取或保存
本轮答复；不会中断已发出的上游模型请求。同步和 SSE 生产者共用同一 arm 接口。

直接答复目前缓冲完整模型回复后发送，尚未实现 token 级流式输出。个人只读域的
模型路由使用合成身份与工具夹具验证过，仍需真实身份下的事实性验收。

## 会话生命周期与写事务

`agent/runtime/turns.py` 提供公共取消信号和会话串行化。PostgreSQL 的会话咨询锁覆盖
读取状态、模型/工具调用、checkpoint 写入整个轮次；使用独立自动提交连接，避免
占满 checkpoint 池或在模型调用期间持有数据库事务。等待有时限且可取消。丢弃末轮
和删除 checkpoint 使用同一把锁；锁在异常、断连或进程退出时释放。

`agent/domains/favorites/transactions.py` 接管已签名的 `favorite_add` / `favorite_remove`
单件确认操作，复核当前身份、权限、会话、过期时间和具体参数，再调用既有收藏工具。
它直接复用 PostgreSQL 幂等账，以签名中的操作 ID 认领并持久化执行结果；重复确认
返回已存结果，遗留 intent 如实报告结果未知。成功必须有工具给出的目标与变更事实，
纯成功文本不能生成完成回执。执行不调用 LLM，也不构造旧规划器计划。

收藏准备由 `agent/domains/favorites/preparation.py` 承担。模型通过小型原生工具选择
`add` / `remove` 和文章 id；代码复核身份、会话、权限、真实文章与本人收藏状态，
再复用现有签名和确认文案生成卡片。状态已达成时零写入、无确认卡，不产生执行回执。
卡片的标题来自 API 数据；本轮浏览器页面信息以结构化元数据传入，仅用于定位候选。
确认令牌不进入模型上下文或工具 trace。准备结果先写入 checkpoint，随后发送既有
`__CONFIRM__` / `__PENDING__` 与单份正文；用户点击确认后进入已有事务执行器。

收藏工具仅在已验签、可写本人数据、稳定会话且已挂 checkpointer 时按需提供。
缺少这些条件时保留旧路径。待确认任务的自然语言修改、取消及多领域组合仍由旧待办流程处理。
同步纯文本入口不提供确认卡控制帧，因此本轮迁移验证面为稳定会话的 SSE / arm 事件接口。

运行时文件已收拢到 `agent/runtime/`，收藏模块位于 `agent/domains/favorites/`。
旧实验臂已退役，主线仅保留 graph/hybrid；归档与结论见
[已退役实验](retired-experiments.md)，目录职责见 [目录说明](repository-layout.md)。

## 请求级对照集

`eval/golden/hybrid_requests.jsonl` 与旧 golden 共用站点语料出处声明，但只按用户可见
结果设断言。通用 Git 知识题允许直接回答；明确问“博客里写过吗”时要求真实检索。
旧 `rag_git_branch` 用例要求任何同题回答都调用站内检索，这是旧架构的内部路径要求；
在新架构下会把正确的通用知识答复判红，因此原用例保留，新对照集另立。

运行方式：

```bash
GOLDEN_ARM=hybrid CHECKPOINT_DSN= .venv/bin/python eval/run_golden.py \
  --golden eval/golden/hybrid_requests.jsonl --min-pass-rate 0
```

该命令关闭本机 checkpoint，只量直接路径。`hybrid` 报告单独存入
`eval/report/runs_hybrid/`；自定义请求集不覆盖默认完整基线。

## 待确认收藏的修改与取消

`agent/domains/favorites/pending.py` 只恢复已验签、绑定当前用户与会话的收藏提议。
模型选择取消或给出新的动作、文章 id；不会通过中文关键词表判断意图。修改先核对新目标，
成功后撤销旧卡并准备新卡；新目标读取失败时保留原待办。普通聊天和读取也保留原卡，不重复发卡。

撤销复用 PostgreSQL 幂等账，以原操作 ID 留下无写入的撤销结果。旧卡即使仍在有效期内、
换进程或重放，也不能执行。已经执行或结果未知的操作不能被声明为取消。签名中的 `executor`
固定收藏执行入口，切换默认运行时不会绕过账本；旧版令牌保持原协议，不恢复到新待办工具。
确认控制帧在 checkpoint 落库之后发送，令牌不进入模型上下文或工具 trace。

SSE 通过既有 `__PENDING__` 通道增加 `event=cancelled`，并在新卡之前发送旧卡取消事件。
宿主后端的 `src/routes/chat/pending.rs` 按用户、会话、task_id、jti 关闭对应行，同一流内顺序处理
取消与新卡登记。需同时升级宿主协议；收藏写入的撤销依据仍是 agent 持久化账本。

本轮真实模型配合 HTTP/身份夹具，取消、自然语言放弃、更换文章、否定取消、闲聊 **5/5** 通过，
11 次模型调用、24,253 输入 token，无旧图交接、无收藏写入。这组小样本不代表全领域成本分位数。
生产 PostgreSQL 使用 8 个独立进程验证取消、替换、旧卡拒绝、新卡执行与重放；仅 1 次模拟工具
执行、0 次真实站点写入，探针会话和幂等记录已清理。报告位于
`eval/report/_smoke_pending_favorite_20261022/{model,postgres}.json`。
